# Theory - Incompressible & Thermal Equations

## Scope
High-level map of the incompressible momentum + scalar transport equations used by standard nekRS setups.

## Key dimensionless groups used across tutorials
- Reynolds number (`Re`)
- Prandtl number (`Pr`)
- Peclet number (`Pe`)
- Richardson number (`Ri`) in buoyancy-driven setups
